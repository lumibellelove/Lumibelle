STAGE 31 MODAL / DETAIL CHECKLIST

[티켓함]
- 현재 티켓 > 상세 보기 열림
- 현재 티켓 > 추억 보기 열림
- 특전권 > 상세 보기 열림
- 지난 티켓 > 추억 보기 열림
- X / 배경 클릭 / ESC 닫힘

[업적/칭호]
- 업적 카드 클릭 시 상세 모달 열림
- 상세 보기 버튼 클릭 시 상세 모달 열림
- 달성 업적 칭호 장착 가능
- 잠긴 업적 칭호 장착 불가
- 프로필의 현재 칭호 반영 확인
- X / 배경 클릭 / ESC 닫힘

[우편함]
- 받은 우편 카드 클릭 시 상세 모달 열림
- 소장 우편으로 보관 버튼 안내 문구 표시
- X / 배경 클릭 / ESC 닫힘

[ON AIR]
- 방송 참여 가이드 열림
- LUMI-4827 입력 후 인증됨
- 중복 인증 안내 표시
- 반짝 응원 버튼 반응
- X / 배경 클릭 / ESC / 확인했어요 닫힘

[숙제체키]
- 상세 보기 열림
- 문의/요청 준비중 버튼 안내 문구 표시
- X / 배경 클릭 / ESC / 확인했어요 닫힘

[가이드]
- 처음 가이드 보기 열림
- 주의사항 보기 열림
- 티켓 안내 보기 열림
- X / 배경 클릭 / ESC / 확인했어요 닫힘

[노래책]
- 마리링 상세 보기 열림
- 루루 상세 보기 열림
- 이로 상세 보기 열림
- 루나 상세 보기 열림
- X / 배경 클릭 / ESC / 확인했어요 닫힘

[교환소]
- 보상 상세 보기 열림
- 교환 신청 준비중 안내 표시
- 노래책 이동 버튼 정상
- X / 배경 클릭 / ESC / 확인했어요 닫힘

[게임존]
- 오늘의 운세 상세 보기 열림
- 출석 체크 상세 보기 열림
- 카드 뽑기 상세 보기 열림
- 랜덤 대사 상세 보기 열림
- 시즌 이벤트 상세 보기 열림
- 룰렛 데이 상세 보기 열림
- 준비중 버튼 안내 문구 표시
- X / 배경 클릭 / ESC / 확인했어요 닫힘

[전체]
- 모달 연 상태에서 다른 탭 이동 시 화면이 깨지지 않는지 확인
- 모달 닫은 후 스크롤/버튼이 정상인지 확인
- PC/모바일에서 모달이 화면 밖으로 심하게 튀지 않는지 확인
