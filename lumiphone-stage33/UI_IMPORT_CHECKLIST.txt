STAGE 20 UI IMPORT CHECKLIST

[기준 원칙]
- 통합본에서 디자인을 가져올 때는 한 탭씩만 진행한다.
- index.html에는 해당 탭 section 내부 구조만 수정한다.
- CSS는 해당 탭 전용 css 파일에만 넣는다.
- JS는 해당 탭 전용 js 파일에만 넣는다.
- app.js는 탭 전환/공통 방어 로직 외에는 건드리지 않는다.

[우선 이식 후보]
1. profile.css / profile.js / profile section
2. ticket.css / ticket.js / ticket section
3. achievement.css / achievement.js / achievement section
4. mail.css / mail.js / mail section
5. onair.css / onair.js / onair section

[확인 항목]
- 탭 이동 정상
- active 표시 정상
- 하얀 화면 없음
- 모달 열기/닫기 정상
- 모바일에서 글자 겹침 없음
- PC 레이아웃은 @media (min-width: 760px) 안에서만 조정
