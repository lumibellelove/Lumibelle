LUMIPHONE MODULAR STAGE 31 - MODAL CHECK BASE

기준: Stage 30 게임존 상세보기 1차 연결본
목적: 전체 상세보기/모달 동작 점검용 기준본

이번 Stage에서 한 일:
- 새 폴더/새 ZIP 생성
- 기능/디자인 대형 변경 없음
- 기존 탭 구조 유지
- 전체 모달/상세보기 점검 체크리스트 추가
- Stage 표기 파일 정리

확인할 것:
1. 티켓함: 상세 보기 / 추억 보기 / 닫기
2. 업적: 상세 보기 / 칭호 장착 / 닫기
3. 우편함: 카드 클릭 / 소장 우편 안내 / 닫기
4. ON AIR: 가이드 모달 / 루미코드 인증 / 반짝 응원
5. 숙제체키: 상세 보기 / 문의 준비중 안내 / 닫기
6. 가이드: 처음 가이드 / 주의사항 / 티켓 안내 모달
7. 노래책: 멤버별 상세 보기 / 닫기
8. 교환소: 보상 상세 보기 / 교환 준비중 안내 / 닫기
9. 게임존: 상세 보기 / 준비중 안내 / 닫기

닫기 방식 공통 확인:
- X 또는 닫기 버튼
- 확인했어요 버튼이 있는 모달은 확인했어요
- 배경 클릭
- ESC 키

주의:
- 아직 실제 운영 데이터 연동 단계가 아님
- 일부 버튼은 준비중 안내 메시지만 표시함
- 팬 화면에 개발용 문구가 보이는지 다음 단계에서 정리 필요
