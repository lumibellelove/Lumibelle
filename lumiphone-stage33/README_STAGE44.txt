Stage 44 - Guide UI Second Pass

기준: Stage 43 숙제체키 UI 2차
수정 범위: 가이드 탭 전용(css/guide.css, js/guide.js)

변경 사항:
- 가이드 카드와 탭의 모바일 가독성 보강
- 처음이에요/라이브/특전회/루미 ID 탭 터치 안정화
- 가이드 상세 모달 버튼 스타일 보강
- iPhone에서 모달 열림 중 뒤 페이지가 밀리지 않도록 스크롤 락 적용
- 긴 안내 내용은 모달 내부에서만 스크롤되도록 보정

확인 순서:
1. 모바일 먼저 확인
2. 가이드 탭 열기
3. 처음이에요/라이브/특전회/루미 ID 탭 이동
4. 처음 가이드 보기 / 주의사항 보기 / 티켓 안내 보기 모달 확인
5. X / 배경 / 확인했어요로 닫기
6. PC에서는 카드 크기와 모달 위치만 가볍게 확인
