Stage 52 Mobile QA Checklist

[공통]
- 아이폰에서 전체 탭 이동 가능
- 갤럭시에서 전체 탭 이동 가능
- 홈 아이콘에서 각 탭으로 이동 가능
- nav active 표시가 어색하지 않음
- 화면 가로 밀림 없음
- 버튼 터치가 먹지 않는 구간 없음

[모달]
- 티켓 상세/추억 모달 열림/닫힘
- 업적 상세 모달 열림/닫힘/칭호 장착
- 우편 상세 모달 열림/닫힘
- ON AIR 가이드 모달 열림/닫힘
- 숙제체키 상세 모달 열림/닫힘
- 가이드 상세 모달 열림/닫힘
- 노래책 상세 모달 열림/닫힘
- 교환소 상세 모달 열림/닫힘
- 게임존 상세 모달 열림/닫힘
- X / 확인했어요 / 배경 클릭 닫기 확인

[특별 확인]
- 노래책 멤버 이모지가 세로로 떨어지지 않음
- 교환소 카테고리 버튼이 잘리지 않음
- 교환소 가격 칩이 상세 보기 버튼과 겹치지 않음
- iPhone에서 확인했어요 버튼이 파란 기본 버튼으로 보이지 않음
- 모달이 열렸을 때 뒤 페이지가 심하게 밀리지 않음
