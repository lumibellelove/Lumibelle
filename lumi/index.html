회차 기준
스탬프 20개를 채우면 1회차 완료 기록이 저장되고, 초기화로 사라지는 것이 아니라 2회차 0 / 20이 새로 시작됩니다. 1회차 완료 기록은 추억의 시간과 스탬프 기록에 남아요.

스탬프 혜택 / 레귤레이션

지급 기준
루미 체크인 완료 시 기본 1일 1스탬프. 라이브만 관람, 물판만 방문, 굿즈만 구매, 촬영 없이 지나간 경우는 제외됩니다.
스탬프 보상은 각 구간을 처음 달성했을 때 1회만 받을 수 있어요. 이미 받은 보상은 다시 지급되지 않고, 보상 기록으로 남아요.
20개 완주 보상 흐름
20개 달성 순간 보상 우편이 도착하고, 업적/칭호 후보가 해금돼요. 현장 보상이 있는 경우에는 루미 ID를 현장에서 보여주면 보상 수령 대기 → 수령 완료로 처리됩니다.
1. 완주 팝업스탬프 20개 완주 안내와 1회차 완료 기록 저장
2. 보상 우편소장 우편 / 칭호 후보 / 업적 해금 도착
3. 다음 회차보상 확인 후 2회차 0/20으로 시작

루미폰은 루미 ID를 가진 팬이 자신의 티켓, 우편, 기록, 스탬프, 업적을 확인하는 개인 기록장이에요.

운영용 처리는 스탭 화면에서 하고, 팬 화면에서는 내 기록과 추억을 보는 구조로 분리해요.

Birthday Ticket은 생일을 등록한 루미 ID 보유자에게 1년에 1회 지급되는 생일 기념 촬영 특전권이에요.

사용 가능 기간과 사용 가능 멤버는 티켓 상세에서 확인해요.

스탬프는 루미 체크인 기준으로 지급돼요. 루미 체크인은 특전권 또는 이벤트권 사용 후 실제 촬영·교류 특전에 참여 완료한 기록이에요.

라이브만 관람, 물판만 방문, 굿즈만 구매한 경우에는 스탬프 지급 대상이 아니에요.

ON AIR는 방송 참여 기록과 루미코드, 반짝 응원을 확인하는 공간이에요.

방송 참여 기록은 물판 포인트와 합산하지 않고, 반짝 포인트/반짝 XP 쪽 기록으로 분리해요.

티켓 정보는 예매/입금/입장 처리 데이터와 연결돼요. 현장 반영 전에는 샘플 또는 이전 상태로 보일 수 있어요.

예약번호, 입금자명, 루미 ID를 기준으로 스탭에게 확인 요청하면 돼요.

스탬프는 방문만으로 지급되지 않고, 루미 체크인 완료 기준으로 지급돼요.

특전회에 참여했는데 누락된 경우 날짜와 사용한 특전권/멤버를 기준으로 확인해요.

물판 포인트, 반짝 포인트, 반짝 XP는 서로 다른 기록이에요. 현장 보상용 물판 포인트와 홈페이지 활동용 반짝 포인트는 합산하지 않아요.

교환소에서 쓰는 포인트는 반짝 포인트 기준으로 정리해요.

PIN을 잊은 경우 닉네임, 루미 ID, 예매 정보, 이메일 등으로 본인 확인 후 재설정하는 흐름을 사용할 예정이에요.

출시 전에는 실제 재설정 기능이 연결되기 전까지 스탭 확인 안내로 처리해요.
