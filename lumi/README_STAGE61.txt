Stage 61 - 칭호 장착 로컬 저장 연결본

기준: Stage 60 프로필 로컬 저장 1차 연결본

변경 사항:
- 업적/칭호 탭에서 대표 칭호를 장착하면 localStorage 데이터에 저장됩니다.
- 새로고침 후에도 장착한 대표 칭호가 유지됩니다.
- 홈 미니 프로필, 프로필 현재 칭호, 프로필 공유 미리보기, 업적 요약 칭호에 같은 값이 반영됩니다.
- 실제 서버/API 연동 전, 기기 안에만 저장되는 1차 저장 구조입니다.

확인 순서:
1. 업적 탭에서 달성 업적의 칭호 장착 버튼을 누릅니다.
2. 프로필 탭과 홈에서 대표 칭호가 바뀌는지 확인합니다.
3. 새로고침 후에도 칭호가 유지되는지 확인합니다.
4. 아이폰/갤럭시에서 버튼이 정상 작동하는지 확인합니다.
