MEMBER 관리

TICKET 페이지 관리

GOODS 관리

굿즈명, 가격, 이미지, 판매 상태, 구매 링크 관리용입니다. 1차 기능 구현 범위는 아닙니다.

SETLIST / 응원가이드 관리

곡별 응원 포인트, 현재 셋리, 신청 가능 여부 관리용입니다. 기존 응원가이드 구조는 보존합니다.

INFO / 인포·가이드 관리

처음이세요, 특전회 안내, 촬영/업로드 규정, 루미폰 안내 등 상시 안내문 관리용입니다.

MORE VIDEO

영상 링크, 썸네일 이미지, 연결 멤버, 연결 페이지를 관리하는 입구입니다. 1차 기능 구현 범위는 아닙니다.

EVENT MASTER

공연/행사 기준 정보를 정리하는 내부 기준 카드입니다. 운영 관리의 예매/입금 흐름과 연결하지 않습니다.
